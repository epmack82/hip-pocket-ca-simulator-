# Market dialogue foundation — local work in progress

22 October 2026. First implementation slice, not a complete encounter redesign.

The supplied Dao playtest is now a pipeline regression case. Interpreter-assisted introductions no longer imply delegated leadership without explicit transfer/departure language. Explicit delegation remains test-covered, but its prose no longer asserts departure merely from delegation.

Named conversation openings, rapport intentions, and alcohol offered as a gift receive separate handling. The gift itself earns no points. Dao's refusal is original fictional character design, not a rule about Thailand or all vendors. Other recipients leave acceptance unresolved. The response is persisted in the site's giftResponses with source action attribution; subsequent respectful withdrawal can acknowledge it. Negated and hypothetical gifts do not establish an event.

The AO schematic is now accessible inside the location screen. It is read-only there: inspecting it cannot travel, consume a slot, or conclude the visit.

Still pending: fuller per-character encounter states, nuanced mixed-action/actor attribution, richer evidence-specific dialogue, complete portraits, menu branding, and visual QA. This remains bounded phrase-based interpretation, not general natural-language understanding. Existing saves with erroneous historical penalties are not silently rewritten.

No reference-library sources or extracts were added. This slice uses original authored behavior and the user's playtest as its requirement. No publication performed.

## 23 October: character accounts and journal

Four original character-specific claim/reply pairs now supply both the evidence ledger and the dialogue. These remain attributed claims, not proven causes. The same speaker's repeated inquiry updates one claim rather than creating independent corroboration. Accepted market exchanges persist in conversationEvents (recipient, original interpreted subject, source action, kind, evidence IDs). The scene displays a collapsible journal. Repeated questions acknowledge the earlier discussion; another character does not inherit that conversation.

An optional person/approach helper appends editable text to the action draft. It never submits, clears existing text, changes world state or silently overrides the player's words. Only present stakeholders are offered. This is a bounded usability aid, not a new semantic model.

Still pending: topic-specific branching beyond the service-access thread, richer disagreement/negotiation, new art and branding, full visual QA. Do not describe this as unrestricted understanding or a finished replayable encounter.
